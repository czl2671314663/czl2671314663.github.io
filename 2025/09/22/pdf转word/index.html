「Python小工具」PDF 转 Word —— 离线安全的文件转换工具

发表于2025-09-22|更新于2026-05-09|编程工具

日常工作和学习中，PDF 转 Word 是高频需求。虽然在线工具很多，但涉及敏感文件时总让人不放心。本文分享一个基于 Python + Tkinter + pdf2docx 开发的离线转换工具，无需联网，数据本地处理，安全可靠。

为什么选择离线工具

对比 在线工具 本工具
隐私安全 文件上传到第三方服务器 数据完全本地处理
网络依赖 必须联网 完全离线可用
文件大小限制 通常 < 10MB 无限制
转换质量 因平台而异 pdf2docx 保真度高
使用门槛 打开网页即可 双击 EXE 即可

功能特性

  • 支持选择本地 PDF 文件，一键转换为 Word（.docx）
  • 自定义 Word 文件输出路径
  • 图形化界面，操作直观
  • 转换完毕自动弹窗提示成功或失败
  • 可打包为独立 EXE，无需安装 Python

使用说明

  1. 选择 PDF 文件：点击按钮选择需要转换的 PDF
  2. 设置输出路径：选择 Word 文件的保存位置和文件名
  3. 开始转换：点击按钮启动转换，完成后弹窗提示

进阶扩展

如果需要更多功能，可以在上述代码基础上扩展：

  • 页码范围：修改 cv.convert(word_file, start=5, end=10) 只转换指定页
  • 批量转换：改为 askdirectory 选择文件夹，遍历所有 PDF
  • 多线程：用 threading 避免大文件转换时界面卡死
  • 进度条：pdf2docx 支持回调函数显示进度
