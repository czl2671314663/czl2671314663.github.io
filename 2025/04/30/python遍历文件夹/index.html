「Python工具」递归遍历文件夹，快速提取、汇总指定类型文件

发表于2025-04-30|更新于2026-05-09|编程工具

在日常数据处理和项目整理中，我们经常需要把散落各处的特定类型文件（如 .csv、.mp4、.cpt 等）从多层目录中提取出来，集中到一个地方。手动一层层翻找效率极低，本文分享一个带 GUI 界面的 Python 文件收集工具。

工具功能概览

  • 递归遍历指定文件夹及其所有子文件夹
  • 支持多选文件后缀（如 .csv + .xlsx + .pdf）
  • 所有匹配文件自动复制到统一的输出目录
  • 保留原始文件（只复制，不移动）
  • 图形化界面操作，选择目录即可
  • 可打包为 EXE，无需 Python 环境

打包为 EXE

打包后会在 dist/ 目录下生成单独的 EXE 文件，双击即可运行，无需安装 Python。

使用说明

  1. 选择源文件夹（程序会递归遍历所有子文件夹）
  2. 选择输出文件夹（所有匹配文件将复制到这里）
  3. 输入要收集的文件后缀，如 .csv .xlsx .pdf（空格分隔）
  4. 点击「开始收集」，右侧日志区实时显示进度
  5. 同名文件自动带序号重命名，不会覆盖

素材整理 提取所有 .jpg / .png / .mp4 到同一目录
代码归档 收集整个项目中的 .py / .sql 文件
